# Security Policy / Güvenlik Politikası

## Türkçe

### Desteklenen Sürümler

| Sürüm | Destek |
|-------|--------|
| 0.1.x | ✅      |
| < 0.1 | ❌      |

### Güvenlik Açığı Bildirimi

Bir güvenlik açığı bulduysanız **lütfen herkese açık bir issue açmayın.**
Bunun yerine, açığı gizli olarak bildirin:

- **E-posta:** `security@segemacro.local` _(placeholder — gerçek adresle değiştirin)_
- **GitHub Security Advisories:** Bu repo için "Report a vulnerability" akışını kullanın.

Bildiriminizde lütfen şunları içerin:

- Açığın türü (örn. RCE, bilgi sızıntısı, ayrıcalık yükseltme).
- Etkilenen dosya/modül ve mümkünse satır numarası.
- Yeniden üretme adımları veya PoC.
- Potansiyel etki.

### Yanıt Süresi

- **İlk yanıt:** 72 saat içinde.
- **Durum güncellemesi:** En geç 7 gün içinde.
- **Düzeltme hedefi:** Önem derecesine göre 30 gün içinde.

### Açıklama Politikası

Sorumlu açıklama (coordinated disclosure) prensibini takip ediyoruz. Düzeltme
yayınlanmadan önce ayrıntıların kamuya açıklanmamasını rica ederiz. Düzeltme
sonrası katkınız için public credit verilir (anonim kalmak istemiyorsanız).

### Kapsam Dışı

- Üçüncü taraf bağımlılıklarındaki açıklar (lütfen ilgili upstream'e bildirin).
- Yerel kullanıcı zaten kök erişime sahipse oluşan riskler.
- Sosyal mühendislik senaryoları.

## English

### Supported Versions

| Version | Support |
|---------|---------|
| 0.1.x   | ✅      |
| < 0.1   | ❌      |

### Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public issue.**
Instead, report it privately:

- **Email:** `security@segemacro.local` _(placeholder — replace with real address)_
- **GitHub Security Advisories:** Use the "Report a vulnerability" flow on this repo.

Please include:

- The type of issue (e.g. RCE, info disclosure, privilege escalation).
- Affected file/module and line number if possible.
- Reproduction steps or PoC.
- Potential impact.

### Response Time

- **Initial response:** within 72 hours.
- **Status update:** within 7 days.
- **Fix target:** within 30 days depending on severity.

### Disclosure Policy

We follow coordinated disclosure. Please keep details private until a fix is
released. Public credit is given for valid reports (unless you prefer to remain
anonymous).

### Out of Scope

- Vulnerabilities in third-party dependencies (please report upstream).
- Issues requiring an already-rooted local user.
- Social engineering scenarios.
